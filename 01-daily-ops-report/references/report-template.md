## 一、模板骨架

```markdown
> ⚠️ 演示数据，非真实经营数据（指纹：…）      ← 仅命中演示指纹时出现

# 📊 每日经营日报 | {yyyy-MM-dd}

## 【L1 结论层】管理层看这里

### 🔴 今日红线（≤5 条，含归因线索）
- **{异常名}**：{昨日值}（基线 {基线值}，偏离 {±x%}）
  - 归因线索：{归因路径}

### 核心指标
| 指标 | 昨日 | 币种/口径 |
|---|---|---|
| GMV（销售额） | … | USD |
| 订单量 | … | — |
| 毛利 | … | USD |
| 毛利率 | …% | 利润口径 settlement |
| ACOS | …% | adCost/adSalePrice |
| CVR | …% | orderNum/sessions |

> ⚠️ 一句话结论：…

## 【L2 明细层】运营看这里

### STEP 01 账户 / 订单 🔴 P0
- 退款数 / 退款金额 / 退货数
- 订单异常下钻样本：N 条（抽样，非全量）
- ⚠️ 账户健康 / 绩效通知 / 买家消息 — 需人工核查

### STEP 02 销售 / 流量 🔴 P0
- GMV / 销量 / 基线方法
- 异常 MSKU（销量环比）：…

### STEP 03 广告
- 广告花费 / 广告销售额 / ACOS
- 活动状态：enabled / paused / archived / unknown
- ⚠️ 高花费零转化：…
- 说明：servingStatus 的 BUDGET_CAPPED 不作判定条件

### STEP 04 库存
- 断货预警 N 项（紧急 M 项）
  - [等级] {msku}：可售 {days} 天，在途 working/shipped/transit

### STEP 05 转化
- Sessions / 订单 / CVR；购物车占比偏低项
- 说明：02 看结果、05 看过程

### STEP 06 售后
- 退款率 / 退款数 / 退货数 / 新增差评数
- ⚠️ 评论原文 — MCP 仅有聚合指标

### STEP 07 政策（无法自动化）
- 状态：⚠️ 需人工核查
- 政策合规 / 绩效风险 — MCP 无此接口

## 【L3 附录】

### 订单异常样本（已脱敏）
- {amazonOrderId}（{店铺}）标记：退货/退款/取消 … buyerEmail: ab***@x.com buyerName: 张*
> 已脱敏：buyerEmail / buyerName 已掩码。

---
### 数据说明（口径 / 覆盖范围）
- 利润口径 / 币种 / 业务日边界 / 数据源 / 数据截止

### ⚠️ 口径降级            ← 有降级时
### ⚠️ 取数覆盖范围（截断披露） ← 有截断时
### 无数据                  ← 有空数据源时
### ⚠️ 本日报未能覆盖        ← 必填
### 参数来源                ← 必填
```

## 二、双读者分层说明

| 层 | 读者 | 内容 | 位置 |
|---|---|---|---|
| **L1 结论层** | 管理层 | 红线清单（≤5）+ 3~6 个核心指标 + 一句话结论 | 顶部 |
| **L2 明细层** | 运营 | 7 步逐项：指标 + 异常 + 归因 + 建议 | 中部 |
| **L3 附录** | 运营 | 异常 ASIN/订单明细、库存预警清单（PII 已脱敏） | 底部 |

顺序原则（SOP 元原则）：**先风险，后经营；先异常，后优化**。
所以 STEP 01 / 07 的风险项和 STEP 02 的异常要**提到最前面**（红线区块），再展开常规数据。

## 三、飞书 block 映射

用 `_shared/scripts/feishu_writer.py`：

```python
from feishu_writer import FeishuWriter
fw = FeishuWriter(folder_token="…")
fw.guard_demo(bundle["data"])              # 演示环境默认阻断，可 override=True
doc_id = fw.create_doc("每日经营日报 2026-09-29")
fw.write_blocks(doc_id, fw.markdown_to_blocks(report_markdown))
```

`markdown_to_blocks` 已按行映射：`#`→heading1/2/3、`-`→bullet、`---`→divider、代码块→code、`>`→quote。
**写入前对 `buyerEmail` / `buyerName` 自动脱敏**（`mask_pii_in_text`）。

### 两个必踩的坑

1. 飞书应用必须被**添加为文档协作者**，否则写入返回 `403`。
2. 创建文档接口限流 **3 次/秒**（错误码 `99991400`），同文件夹创建必须**串行**。

## 四、不可省略的区块

以下四块**缺一不可**，否则日报失去可信度：

1. **「本日报未能覆盖」** —— 列出 MCP 无数据源的项（账户健康、买家消息、政策、评论原文），标「⚠️ 需人工核查」。
2. **数据说明** —— 利润口径 / 币种 / 业务日边界 / 数据源 / 数据截止时间。
3. **参数来源** —— 阈值、report_id 等的来源（配置命中 / 本次填写 / 默认值），默认值必须显式标注。
4. **截断/降级/无数据披露**（如有）—— 禁止静默。
