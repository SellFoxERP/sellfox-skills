# 赛狐经营技能包

用自然语言查看经营情况、排查异常、整理运营建议。面向使用赛狐 ERP 的跨境电商商家，包含 1 个通用技能和 9 个专项技能，**一次批量安装，共用一份店铺、报表和阈值配置**。

通用技能和十一个专项技能均通过 MCP 取数；批量数据处理与报告计算需要本地 Python 3.10+。通用技能附带独立的标准库脚本，不依赖专项技能。适用于提供相应能力的 AI 客户端，WorkBuddy 是其中一个使用示例。不同客户端的安装目录、MCP 配置格式和技能启用方式需按实际环境设置；本项目不限定客户端品牌。

## 可以帮你做什么

| 技能 | 可以直接这样问 | 结果与边界 |
|---|---|---|
| 通用业务 `sellfox-business` | 查询店铺、订单、库存和利润，按我的问题分析 | 八个业务域按需调用 MCP；修改需具体授权 |
| 经营日报 `daily-ops-report` | 生成昨天的经营日报，列出优先处理的问题 | 本地报告；缺报表时披露指标缺口 |
| 库存健康 `inventory-health` | 哪些商品快断货了，哪些库存积压？ | 断货/滞销预警与补货建议；不创建采购单 |
| Listing 体检 `listing-health` | 检查不可售、购物车和转化问题 | 诊断清单；不修改商品 |
| 周月复盘 `weekly-review` | 汇总上周经营表现，与上期比较 | 指标、榜单、目标达成；目标需先填写 |
| 利润诊断 `profit-diagnosis` | 分析最近 30 天利润下降的原因 | 利润变化归因；缺成本信息会降级 |
| 广告优化 `ad-optimizer` | 分析广告浪费，先给调整提案 | 默认只出提案；批准后才由 AI 调用写工具 |
| 指标治理 `metric-governance` | 检查自定义指标与公司口径是否一致 | 对比提案；公式未确认不写入 |
| 上架素材 `listing-launch` | 为这款商品准备标题、五点和素材需求单 | 文案/素材包；不自动刊登；成本缺失不计算完整利润 |
| 评论分析 `voc-insight` | 分析评分下降和差评主题 | 聚合指标定位；评论原文需另外接入，缺原文不做主题归因 |

新增专题：[退款退货损失分析](11-returns-loss/SKILL.md)、[新品上市复盘](12-new-product-review/SKILL.md)。例如：“复盘最近30天退款退货损失，先按商品列出金额与缺口”“复盘上架30天内新品，按上市年龄评价，不自动改广告”。两个专题复用完整安装包中的通用 Python 组件。

库存技能增加补货情景和货件跟进，Listing 技能增加销量下降排查，利润技能增加促销定价测算。

通用入口采用 [SKILL.md](10-sellfox-business/SKILL.md) 索引 + [references](10-sellfox-business/references/) 业务域指南，覆盖店铺、销售统计、订单、产品、物流、财务、广告和报表。临时查询与跨域任务用通用入口；固定报告可继续使用专项技能。

## 开始使用

1. 阅读 [安装指南](INSTALL.md)，在所用 AI 客户端中配置商家自己的 Sellfox-MCP 地址和 Key。
2. WorkBuddy 可添加本仓库为市场，安装一次 `sellfox-skills` 即获得十二个技能；其他客户端下载完整仓库或 `sellfox-skills.zip`，按安装指南运行批量安装器。两种方式选一种。
3. 在新任务中启用技能及连接器，先说：**“检查赛狐连接和技能环境，只做只读检查。”**
4. 再说：**“生成昨天的经营日报，保存本地，不发送飞书；缺少的数据请明确说明。”**

需要自定义报表时，助手自动发现报表名称与 ID，核对用途后使用；多个候选时只需选择名称，无需手填 ID 或修改配置。没有可用报表时继续简版并说明缺口。已保存的选择升级保留。

安装器需要 Python 3.10+。商家可让 AI 助手根据 [INSTALL.md](INSTALL.md) 执行安装，不必手工运行分析脚本。

## 数据与操作范围

- 赛狐数据由 AI 通过客户端配置的 MCP 读取；本地 Python 完成校验、计算和报告生成。
- Key 只填在客户端连接器配置中，不填进技能文件、聊天示例或 GitHub。
- 默认保存本地报告。飞书文档、审批通知属于可选联网功能；只有用户要求时启用。
- 广告调整、指标修改先展示对象、前后值和影响，得到批准后执行；结果未知时先核实，不自动重放。
- 原始数据、输出报告、运行日志均不应上传到 GitHub。测试样例为合成数据，不能用作经营结论。

## 验证状态

本仓库提供可重复运行的离线能力测试和发布检查。具体通过项目、MCP 只读验证及尚未验证的功能见 [验证报告](docs/VALIDATION.md)。**本机测试不等同于 各客户端的技能发现、自动触发或生产业务口径认证。**

## 给维护者

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/audit_release.py
python3 scripts/build_release.py
```

Windows 可将 `python3` 换为 `py -3`。批量安装包与 SHA256 校验文件生成在 `dist/`，作为 GitHub Release 附件上传；源码提交范围和发布检查见 [发布说明](docs/RELEASE.md)。

目录：`01~12-*` 为技能源码；`_shared` 为统一底座；`tests` 为合成测试与人工评测场景；`scripts` 为维护工具。`_internal` 是本地历史资料，不发布。
