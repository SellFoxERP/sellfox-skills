# 上架素材包模板（Listing Package Template）

> 渲染上架包时严格使用本模板。实现：`scripts/render_package.py`。
> 缺少任何区块都视为交付不完整；末尾「诚实边界 / 数据说明」**不可省略**。

---

## 完整结构

```markdown
📦 Listing Package: {产品名} | {站点} | {日期}

[演示环境命中时，此处加水印：⚠️ 演示数据，非真实经营数据]

## 1. 市场与竞品调研
   - 竞品 Top ASIN 的标题/价格/评分/BSR（赛狐 get_product_analyze_list，或外部 MCP）
   - 关键词与搜索趋势（外部 MCP / 人工）
   - ⚠️ 未接入外部情报源时，本节标「需人工核查」

## 2. Listing 文案
   **标题 Title：** …
   **五点 Bullets：** 1~5
   **搜索词 Search Terms：** …
   **商品描述 / A+：** …

## 3. 素材需求单 asset-brief.json
   | id | 类型 | 角色 | 关键规格 | 提示词（摘要） |
   **生成数量：** 图片 N 张 + 视频 M 个 ｜ **预估成本：** …

## 4. 生成的素材文件
   - 外部 MCP 产出；未经成本确认前留空

## 5. 合规检查清单（写前咨询，永不写入）
   - 禁用/高风险表述命中（如有）
   - 字符/字节校验结果
   - AI 素材披露提示
   - 免责声明

## 6. 定价与利润测算
   - 售价口径币种 / 成本口径币种
   - 售价 / 采购成本（含汇率换算）/ 成本合计
   - 预估毛利 / 毛利率 / 建议售价

## 7. ⚠️ 待人工确认项
   - 逐条列出

---
### ⚠️ 本技能未能覆盖 / 需人工核查（诚实边界）
- 不能自动刊登商品（赛狐 MCP 无创建/修改 Listing 接口）
- 字符/字节限制未验证，须按官方核对
- 商标/专利/资质无数据源
- 评论原文不可得（仅聚合指标）
- 头程成本仅存在于 get_custom_report_page_list

### 数据说明与警示
- 截断披露 / 演示环境 / 口径降级 等

数据日期：{日期} ｜ 数据源：赛狐 ERP（SellFox MCP）
```

---

## 渲染规则

| 规则 | 说明 |
|---|---|
| 区号 | 严格 1~7，顺序不变 |
| 空区块 | 标「需人工核查」或说明原因，**不留空、不写 0** |
| 币种 | 每处金额标注币种；跨币种注明汇率来源与日期 |
| 截断 | 取数被截断时，顶部数据说明披露覆盖范围 |
| 演示环境 | 命中指纹 → 顶部水印 + 默认阻断写飞书 |
| 素材披露 | 含 AI 生成素材时，保留 AI 披露提示 |

---

## L1/L2 分层建议

上架包面向**运营 + 设计 + 主管**协作，可分层阅读：

- **L1 主管/决策层**：区块 6（定价测算）+ 区块 7（待确认项）+ 诚实边界
- **L2 运营/设计层**：区块 1~5 明细

写入飞书后，主管看财务与风险，运营/设计看文案与素材。
