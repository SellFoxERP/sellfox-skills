# 商家报表初始化（九个技能共用）

商家说“配置赛狐”“配置报表”“暂时没有报表”或首次业务任务缺报表时使用本流程。不要要求商家找配置文件、改 YAML 或设置环境变量。共享目录只存程序和默认值；商家报表选择写到用户主目录 `.sellfox-skills/config/reports.json`，跨客户端共用，升级保留。不要在此保存 MCP Key。

## 先检查，业务任务不被配置打断

定位当前技能使用的共享目录，运行 `<共享目录>/scripts/merchant_setup.py status`（Python 3.10+）。不主动修改商家日常客户端设置。

- `verified`：自动使用已保存 ID；表示当时可读取，不代表所有字段齐全或永久授权。
- `legacy`：兼容旧 reports.yaml 中的 ID，不主动覆盖；商家要求迁移时按下面流程重新验证后保存。
- `deferred`：用户已明确选择简版，**不再询问配置**。继续业务任务，报告仍说明缺失字段。
- `unset`：先运行能做的简版；只有任务需要该报表的增强能力时，简短说明收益并提供“现在配置 / 暂不配置”选择。不要一次追问三种报表。没有回答不等于选择暂缓，不擅自保存 deferred。
- 配置损坏：说明无法读取，保留原文件和备份；不把损坏配置静默当作未配置。

商家主动说“帮我配置赛狐经营报表”时，以经营报表 daily_ops 为入口。库存用 inventory，利润用 profit；不要未经检查把同一个 ID 填进所有用途。选择“暂不配置”后运行 `merchant_setup.py defer --kind <用途>`。这只清空该用途的有效 ID，其他用途保持不变；已有配置时明确说明将切换为简版。以后商家主动要求配置即可再次进入。

## 商家只提供 ID，助手负责验证和保存

1. 说明在哪里取得：赛狐网页端的自定义报表。报表用途：经营（库存/流量/广告/评论/退款），库存（在途/库龄/可售天数），利润（采购/头程/赔偿/延期结算）。界面未显示 ID 时让商家向赛狐管理员索取；不假装能自动创建报表。
2. 不索取 MCP Key。商家粘贴链接时，不直接保存或打开其中的凭证参数；目前没有经过验证的链接提取规则，要求明确报表 ID，不猜测 URL 中数字。
3. 按 SELLFOX_CLIENT.md 获取 `get_custom_report_page_list` 的当前完整契约，确认日期、范围、币种等必填条件，再用该 ID 做一次最小只读查询。ID 不属于店铺 ID，不相互替换。失败、unknown、partial 或响应 ID 不符时不覆盖旧配置；保留具体失败原因。
4. 成功返回 rows 后，核对日期、范围及用途需要的字段。空 rows 只能证明请求可读取，说明“暂无数据，字段待验证”；有数据但筛选不符时不保存。缺少部分字段要说明降级，不能宣称完整报表已就绪。
5. 在本次任务的本地 out 目录保存验证证据 JSON（不上传仓库），格式如下。request 是实际 action 参数，response 是完整业务信封，不自行生成成功响应：

```json
{
  "request": {
    "tool_id": "get_custom_report_page_list",
    "contract_version": "本次契约版本",
    "params": {"report_id": "商家提供的ID"}
  },
  "response": {"完整业务信封": "保留实际返回的所有字段"}
}
```

6. 运行 `merchant_setup.py save --kind <daily_ops|inventory|profit> --id <ID> --evidence <证据文件>`。脚本检查请求与响应、保留旧配置备份并原子写入；脚本不联网，不代替助手核对字段/日期。命令参数须安全传递，禁止把商家文本作为 shell 代码拼接。
7. 再运行 status，告知“已保存、九个技能会自动读取；可用能力与仍缺字段”。需要时重新启动本次业务脚本读取新值，无需让商家重新安装。

## 兼容与隔离

读取优先级：业务脚本显式 `--report-id`（支持时）> 独立用户配置 > 原共享 reports.yaml 默认值。deferred 明确关闭对应旧 ID。旧路径与 SELLFOX_SHARED_ROOT 仍只负责定位共享代码/默认配置。

一个系统用户默认共用一套报表配置，**不能跨不同商家账号自动复用 ID**。切换 MCP 账号后先重新验证；多人/多账号隔离可由管理员用 SELLFOX_USER_CONFIG_DIR 指定独立目录，普通商家无需设置。该变量也用于测试，测试不得写入真实用户配置。

本版独立保存范围是报表 ID 和暂缓选择；店铺、阈值、到货周期、目标等原配置及运行报告仍按原规则管理，不宣称这些已全部迁移。
