## MCP 验证证据

- 初始化与 tools/list 成功，服务暴露 help/search/action。
- 工作流涉及的 **26 个业务工具**均成功读取当前契约。一次 5 工具批次因契约长度预算部分返回，随后仅对失败项缩小批次成功读取。
- 店铺列表读取：`status=complete`，返回 20 行，coverage 声明完整。本次请求更小页数仍返回 20 行，因此没有把请求页大小当成返回数量保证。
- 在线商品读取：`status=complete`，返回 3 行，coverage 声明完整。
- 商品响应带 `documented_schema_mismatch`，包括文档预期字符串但返回数值/null 等差异；诊断信息被服务截断。未修改原响应，Listing 流水线正常生成报告，并披露“原值保留”等警告。
- 上述覆盖仅针对该次响应和当前测试服务。警告明确表示业务口径未认证，不能据此推断生产全量或财务准确。
- 实际响应及生成报告保存在仓库外临时目录，未写进发布源码、测试 fixture 或 Release。

## 已修复问题

1. **状态校验**：失败、unknown 或缺失状态的响应不再输出可计算数据行，完整原响应仍保留；校验器对这些状态返回失败。
2. **指标清单可信度**：partial/unknown/failed、覆盖不完整或列表结构缺失时禁止推断“指标缺失”；更新不再用指标名冒充真实 ID。
3. **VOC 假成功**：子进程失败立即停止，避免读取旧产物后仍显示完成。
4. **VOC 配置解析**：多行关键词列表在无 PyYAML 时被当字符串；改为内置解析器支持的列表格式，补默认配置匹配测试。日报块标量也改为等价兼容格式。
5. **路径**：日报中间文件和报告统一到技能根目录 out；底座兼容源码布局，批量安装使用同一共享目录。
6. **汇率**：缺币种、非正数/无效汇率、缺来源或日期时不给换算结果。
7. **上游警告**：Listing 与日报的数据说明保留警告；字段字典不再冒充全量或生产认证。
8. **发布文档**：补批量安装、商家提问示例、升级保留配置、实际能力边界；修正传输类型、固定分页上限、旧契约及缺失调研文件引用。
