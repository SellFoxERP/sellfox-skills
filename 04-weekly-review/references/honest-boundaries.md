# 诚实边界与需人工核查项（honest-boundaries.md）

> 从 SKILL.md 引用。**当输出结论、或用户问「为什么报告里没有 X」时读本文件。**
> 声称做不到的能力会摧毁信任 —— 宁可显式留白，也不编造、不用 0 冒充「没拿到」。

## 一、本技能**做不到**什么

- **不覆盖非赛狐数据源**：账户健康、绩效通知、买家消息/工单、政策合规、评论原文，
  赛狐 MCP 均无接口 → 一律标注「⚠️ 需人工核查」，**不编造**。
- **不做广告活动级自动归因**：`servingStatus` 取值 `BUDGET_CAPPED` **未经实测验证**，
  不得作为诊断规则；`state` 只用实测确认的 `enabled` / `paused` / `archived`。
  活动级预算/竞价诊断属于技能 6（读写技能），本技能只做经营层趋势与结构。
- **不写入赛狐**：本技能是**只读**技能，唯一写入目标是「报告文档」（飞书），
  且默认关闭、演示环境默认阻断。
- **不做利润异常深归因**：成本/赔偿/延期结算等的逐项归因属于技能 5（利润异常诊断），
  本技能只回答「本期 vs 上期/同期 涨跌了多少」。
- **不保证跨币种聚合**：未配置折算币种时按币种分组，**不跨币种相加**。

## 二、字段缺失 → 处理方式

| 情形 | 处理 |
|---|---|
| `data:{}` / `null` | 标「无数据」，**不写 0**，**不重试** |
| 字段在响应里不存在 | 标「⚠️ 需人工核查」，**不臆造字段名** |
| 分母为 0 | 标「不适用」，不输出 `inf`/`NaN` |
| 源调用报错 | 该源降级，其余继续；报告「数据说明」列出失败源与原因 |
| Top/Bottom 行数不足 | 标「榜单覆盖不足」，结论仅供参考 |
| 命中 `max_rows` 截断 | **必须披露覆盖范围**；禁止把截断结果读成「已覆盖全部」 |

## 三、口径相关的人工核查点

1. **利润口径**：`settlement`（结算，默认）vs `shipment`（发货）—— 同一时间段结果不同，
   不标注必然与财务对不上账。每次输出都必须标注。
2. **销售额口径**：利润报表 `productSales` 与自定义宽表 `salePrice` 口径是否一致，
   需与业务/财务确认后写入 `_shared/METRIC_FORMULAS.md` 的「___」处。
3. **上月同期定义**：本技能约定「当前窗口整体前移一个自然月」；若财务有别的定义，
   需在 `METRIC_FORMULAS.md` 中固化，避免各技能口径分叉。
4. **周目标**：`targets.yaml` 目前只有月/季/年目标；周报达成率用「本月累计 vs 月目标」，
   需要独立周目标时再扩展配置，**不得擅自摊派**。
5. **时区**：US/EU/JP 业务日边界不同，跨站点聚合时以赛狐 `bizDay` 为准并标注。
6. **榜单标识列字段名（待核实）**：`get_profit_report_by_msku` 的 MSKU/ASIN/标题字段名
   **未在 `01`/`06` 中确认**（`06` 中 `msku`/`asin`/`sku`/`title` 的「出现于」均不含该工具，
   `01` 亦未列出）。本技能**不臆造**字段名：只在 `weekly.yaml → rank_identifiers` 候选里命中时取值，
   取不到的行标「⚠️ 需人工核查」，并在报告 Top/Bottom 表上方与「数据说明」注明
   「标识列字段名待核实」。用一份真实响应核对后，把确认字段名填入候选首位并置 `verified: true`。
   （注意：早期草稿里的 `sellerSku` / `productName` 兜底字段来自其它工具甚至不存在，已移除。）

## 四、演示环境（运行期识别，非文档提醒）

数据源可能是演示/沙箱环境（以客户端配置的端点/Key 为准）。指纹：`MOCK-` 前缀 / `demo.example.com` /
店铺名含「演示」。

- 命中 → 报告顶部水印「⚠️ 演示数据，非真实经营数据」+ `meta.mock=True`；
- 默认**阻断**飞书写入（需显式 `--override-demo`，且仍保留水印）；
- 演示数据**只能**用于验证接口连通性、参数格式、字段名、分页与错误处理，
  **不可**用于验证任何业务口径。

## 五、图表能力的边界

- 趋势图优先用 `get_product_analyze_detail` 返回的 `charData`；**该字段若未返回**，
  降级为利润报表 `bizDay` 日粒度序列并标注「charData 缺失，降级」。
- 本技能内建 Mermaid 文本图；要渲染成图片需接**外部图表 MCP**
  （如 `antv/mcp-server-chart` / `hustcc/mcp-echarts`），未接入时只能输出图表源码。
- **未接入图表 MCP 时不假装有图**。
