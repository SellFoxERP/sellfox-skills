# 报告模板（report-template.md）

> 从 SKILL.md 引用。**渲染报告前读本文件**；`render_report.py` 严格遵循此结构。
> 缺少「数据说明」区块的报告视为不合格。

## 结构总览

```
📈 经营周报/月报｜{起止日期}
  （演示数据水印，命中时置顶）

## 核心结论          ← 管理层先看这里：异常/红线（≤5 条，含归因线索）
## 目标达成率        ← 本期 vs 目标；无目标则标注「无法计算」
## 核心指标          ← 本期 / 上期 / 环比 / 上月同期 / 去年同期；含宽表指标（会话数/ACOS/广告转化率/可售天数）
## 趋势              ← charData 或 bizDay 降级序列（可配 Mermaid）
## Top ASIN 榜       ← 按销售额（利润报表口径）
## Bottom ASIN 榜    ← 按毛利升序（利润报表口径）
## 店铺明细          ← L2：按店铺拆解
---
### 数据说明          ← 必填：口径、币种、时区、数据源、覆盖与降级
### ⚠️ 本报告未能覆盖  ← 诚实边界
```

## 飞书 block 映射

`render_report.py` 产出标准 Markdown；写入飞书时走
`_shared/scripts/feishu_writer.py` 的 `markdown_to_blocks()`：

| Markdown | 飞书 block |
|---|---|
| `#`~`####` | 标题 1~4 |
| `-` / `*` | 无序列表 |
| `>` | 引用块 |
| `---` | 分割线 |
| 表格 / 段落 | 普通段落（表格以文本形式呈现） |

写入注意：
1. 应用必须先被**添加为文档协作者**，否则 403；
2. 先建文档 → 追加 block → 校验（避免 block 索引问题）；
3. 创建限流 **3 次/秒**（错误码 `99991400`），同文件夹创建必须串行；
4. 写入前自动过 **PII 脱敏**，文末标注「已脱敏」；
5. 演示环境默认**阻断**写入。

## 显示规则

- 空值/缺失 → `不适用` 或 `无数据`；**绝不写 0**。
- 比率统一带 `%`；金额用千分位。
- 达成率评级：🟢 达标 / 🟡 预警 / 🔴 未达标 / ⚪ 数据不足（分级线来自 `targets.yaml.achievement`）。
- 截断/降级必须出现在「数据说明」，不能只在控制台打印。
